# 🦄 유니콘 구구단

송지안을 위한 1~12단 구구단 학습 웹앱 (PWA). 설치 없이 브라우저에서 열고, 갤럭시탭 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 학습 구조
- **모험 길**: 독일 학교 순서(핵심 단 → 유도 단)에 맞춘 4개의 섬
  - 🏝️ 시작 섬 1·2·10·5단 → 🍭 사탕 섬 4·3·6단 → 🐬 바다 섬 9·8·7단 → 🌌 별빛 섬 11·12단 → 🏆 졸업 시험
  - 단마다 👀 만나기(듣고 따라 하기) → ✏️ 연습 1·2 → 🔀 섞어 풀기 → ☁️ 먹구름(보스)
- **뒤로 가지 않기**: 진행 막대는 앞으로만 가요. 틀린 문제는 조금 뒤에 고르기 문제로 다시 나와요. 점수·정답률은 보여주지 않아요.
- **먹구름 보스**: 맞힐 때마다 구름이 맑아져요. 틀려도 잃는 건 없어요.
- **간격 반복**: 문제(144개)마다 실력 상자를 기록해서 헷갈리는 문제가 더 자주 나와요. 상자는 레슨마다 한 칸만 올라요.
- **🧩 지도**: 12×12 표에서 ⬜ 아직 / 🟨 배우는 중 / 🟩 외움 / ⚡ 3초 안에 바로 나옴을 한눈에. 🪞 짝꿍 찾기(3×7 = 7×3).
- **⚡ 번개 모드**: 외운 문제를 3초 안에 바로 꺼내는 연습 + 🎸 60초 챌린지(내 기록 깨기).
- **보상**: 레슨마다 스티커, 보스마다 메달, 그날 새로 외운 문제 수(4·10·18개)에 따라 보물상자. 출석 체크는 없어요.
- **💡 도움**: 요령은 문제 화면에 띄우지 않고, 💡를 누르거나 틀렸을 때만 묶음 그림과 함께 보여줘요.

## 소리
- `audio/de/*.mp3`: 독일어 음성 (오프라인 신경망 TTS `piper thorsten-high`, Whisper로 144개 모두 받아쓰기 확인)
- `audio/ko/*.mp3`: 한국어 음성 파일이 있으면 그걸 쓰고, 없으면 기기 음성으로 구구단 리듬("삼칠, 이십일")을 읽어요.
- 음성 파일 다시 만들기: `tools/gen_audio.py` 참고
  ```bash
  pip install edge-tts
  python3 tools/gen_audio.py --engine edge --lang ko   # 한국어 (내 PC에서, 인터넷 필요)
  ```

## 배포 (GitHub Pages)
레포 Settings → Pages → 브랜치 선택 → `/ (root)`. 빌드 과정 없이 정적 파일 그대로예요.
기록은 기기 브라우저(localStorage)에만 저장돼요.
